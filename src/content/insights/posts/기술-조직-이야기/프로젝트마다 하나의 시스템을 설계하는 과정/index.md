# 프로젝트마다 하나의 시스템을 설계하는 과정

샘튼은 여러 소프트웨어를 단순히 묶어 제공하지 않습니다. 현장과 업무를 먼저 분석하고, 검증된 엔진을 필요한 구조로 조합해 하나의 완성된 시스템을 설계합니다.

이 구조는 데이터와 규제, 업무 범위가 바뀌어도 필요한 부분을 유연하게 확장할 수 있다는 장점이 있습니다.
