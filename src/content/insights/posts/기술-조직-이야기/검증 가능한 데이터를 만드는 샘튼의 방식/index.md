# 검증 가능한 데이터를 만드는 샘튼의 방식

샘튼의 소프트웨어 엔진은 원천 데이터 연결, 표준화, 품질 검증, 방법론 적용과 증빙 생성을 하나의 처리 흐름으로 구성합니다.

각 단계의 입력과 결과, 변경 이력을 함께 보존해 최종 데이터가 어디에서 어떻게 만들어졌는지 확인할 수 있도록 설계합니다.
