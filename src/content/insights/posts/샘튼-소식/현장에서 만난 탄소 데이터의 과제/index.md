# 현장에서 만난 탄소 데이터의 과제

탄소 데이터는 현장의 장비, 업무 방식과 기록 체계에서 시작합니다. 같은 사업이라도 데이터의 형식과 수집 주기, 담당자의 업무 흐름이 다르기 때문에 실제 운영 환경을 먼저 이해해야 합니다.

샘튼은 현장에서 확인한 조건을 데이터 구조와 시스템 설계에 반영합니다.
