# 샘튼,

샘튼은 기업과 공공기관, 현장 파트너와 함께 탄소·환경 데이터를 실제 업무에 연결하는 프로젝트를 진행합니다.

각 프로젝트의 목표와 현장 조건에 맞춰 검증된 소프트웨어 엔진을 조합하고, 하나의 맞춤형 시스템으로 구축합니다.
